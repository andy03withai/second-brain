## ⚠️ Git 工作区教训（重要，下次复用）
- 本工作区 repo 根目录是 `/root/.openclaw/workspace`（不是 content/），second-brain 远程结构带 `content/` 前缀
- ** push 被拒 + rebase 报 "untracked working tree files would be overwritten" 的标准处理**：
  1. `git fetch second-brain main`，`git diff --name-only --diff-filter=A HEAD second-brain/main` 找远程新增文件
  2. 逐个 `diff <(git show second-brain/main:文件) 本地文件` 确认内容一致后删除本地未跟踪副本
  3. `git pull --rebase second-brain main`
  4. 旧提交（如 11-23 的 152943cc）与远程已推送版本（69547dbd）冲突时：索引用 `git checkout --ours`（取远程更新的索引），新提交冲突用 `git checkout --theirs`（取自己的新增行）
  5. 注意 `cmd1 && cmd2` 链中 cmd1 失败会跳过 cmd2——别用长 && 链做关键删除
- 主仓库 origin（memoir-app）PAT 过期是预先存在问题，与 Pages 发布无关；只推 second-brain 远程
