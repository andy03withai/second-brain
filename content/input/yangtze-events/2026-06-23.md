# 长三角城市活动周报（2026.06.23 - 06.29）

> **本周概览**：本周长三角地区文化科技活动精彩纷呈。上海博物馆东馆两大特展持续展出，浦东美术馆奥赛博物馆艺术瑰宝展进入最后阶段；南京六朝博物馆"郁郁乎唐"特展、江宁织造博物馆《大梦·红楼》沉浸式展演持续热映；苏州博物馆西馆"拿破仑与法兰西的变革时代"特展于6月26日开幕。科技领域方面，上海科技馆焕新升级后研学活动持续推出。户外与亲子领域，上海自然博物馆"趣玩研学"系列、南京户外极限运动赛等适合家庭参与。本周正值暑期来临，各地博物馆、科技馆纷纷推出面向青少年的特色活动。

- **活动时间**：2026年6月上旬 - 9月上旬（周二至周日9:00-17:00，16:00停止入馆）
