## 核心摘要

> **一句话**：用唐朝三省六部制解决 Multi-Agent 协作混乱问题——让 AI Agent 像赛博官僚一样各司其职、相互制衡。

**一段话**：Edict 是一个基于 OpenClaw 的多 Agent 编排系统，借鉴唐朝官僚体系设计。系统由 12 个 AI Agent（11 业务角色 + 1 兼容角色）组成：太子（消息分拣）、三省（中书/门下/尚书）、七部（户/礼/兵/刑/工/吏/早朝官），以及军机处 Kanban。相比 AutoGen 的"群聊模式"，Edict 采用单向信息流动和层级审批机制，避免 Agent 寒暄偏离主题。

## 通过写作消化

### 核心论点
1. **制衡优于群聊**：门下省可"封驳"打回中书省方案，避免 AutoGen 式无约束讨论
2. **层级结构确保可预测性**：信息单向流动（皇帝→中书→门下→尚书→六部）
3. **人格化 Agent**：每个 Agent 有 SOUL/MEMORY/IDENTITY，非冷冰冰工具
