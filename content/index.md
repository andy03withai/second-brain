# 🧠 欢迎来到我的第二大脑

这里是我收集、整理、学习和消化知识的地方。

## 🚀 快速使用

### 文章收录
```
/sb https://example.com/article 你的批注（可选）
/sb URL1 URL2 URL3 批注          # 多链接主题收录
```

### 深度调研
```
/r <主题> [--depth standard|deep|comprehensive]
```

### 书籍记录
```
/book <链接> 批注                 # 从亚马逊/豆瓣链接添加
/book 《书名》 读书笔记           # 添加读书笔记
```

> ⚠️ **重要**：只有以 `/sb`、`/r` 或 `/book` 开头的消息才会触发工作流。
