# 第二大脑使用指南

## 🎯 如何使用

### 1. 发送文章链接

在飞书对话中直接发送：

```
https://example.com/article 这篇文章讲AI产品设计的，观点很有意思
```

格式：`链接` + `空格` + `你的批注（可选）`

### 2. 我会自动处理

- 提取文章内容
- 生成结构化笔记
- 分析信息增量
- 推送到网站

### 3. 查看结果

网站地址：https://andy03withai.github.io

大约 2-3 分钟后可查看最新内容。

## 📁 内容结构

```
content/
├── index.md          # 主页
├── articles/         # 收录的文章
│   ├── 2026-03-09-xxx.md
│   └── ...
└── templates/        # 模板
```

---

## 🏷️ 标签系统

自动标签（基于内容分析）：
- `#AI` - 人工智能相关
- `#产品` - 产品设计、用户体验
- `#技术` - 编程、架构
- `#商业` - 商业模式、市场分析
- `#思维` - 认知、方法论

---

## 🔍 功能特性

- **全文搜索** - 支持搜索所有收录内容
- **标签筛选** - 按主题浏览
- **双向链接** - 相关文章自动关联
- **图谱视图** - 知识结构可视化
- **RSS订阅** - 获取更新

---

## 💡 提示

- 批注越具体，后续检索越方便
- 可以发送任何网页链接
- 支持微信公众号文章（需复制链接）
- 支持 YouTube/Bilibili 视频（提取字幕摘要）
