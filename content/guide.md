# 第二大脑使用指南

## 🎯 如何使用

### 1. 使用 `/sb` 命令发送文章

在飞书对话中发送：

```
/sb https://example.com/article 这篇文章讲AI产品设计的，观点很有意思
```

格式：**`/sb`** + `空格` + `链接` + `空格` + `批注（可选）`

> ⚠️ **重要**：只有以 `/sb` 开头的消息才会触发第二大脑收录流程。普通对话不会进入工作流。

### 2. 普通对话

如果不加 `/sb`，我们的对话就是普通聊天，不会保存到第二大脑。

```
用户：你觉得这篇文章怎么样？
我：普通回复，不保存
```

### 3. 处理流程

收到 `/sb` 命令后，我会：
- 提取文章内容
- 生成结构化笔记
- 分析信息增量
- 推送到网站

### 4. 查看结果

网站地址：https://andy03withai.github.io/second-brain/

大约 2-3 分钟后可查看最新内容。

## 📁 内容结构

```
content/
├── index.md          # 主页
├── articles/         # 收录的文章
│   ├── 2026-03-09-xxx.md
│   └── ...
└── templates/        # 模板
```

---

## 🏷️ 标签系统

自动标签（基于内容分析）：
- `#AI` - 人工智能相关
- `#产品` - 产品设计、用户体验
- `#技术` - 编程、架构
- `#商业` - 商业模式、市场分析
- `#思维` - 认知、方法论

---

## 🔍 功能特性

- **全文搜索** - 支持搜索所有收录内容
- **标签筛选** - 按主题浏览
- **双向链接** - 相关文章自动关联
- **图谱视图** - 知识结构可视化
- **RSS订阅** - 获取更新

---

## 💡 提示

- 批注越具体，后续检索越方便
- 可以发送任何网页链接
- 支持微信公众号文章（需复制链接）
- 支持 YouTube/Bilibili 视频（提取字幕摘要）
