# 设计数据密集型应用

**作者**: Martin Kleppmann  
**原书名**: Designing Data-Intensive Applications  
**分类**: [[books/distributed-computing/index|分布式计算]]  
**状态**: 🔵 想读

## 简介

本书从底层数据结构到分布式系统架构，全面讲解了现代数据系统的原理。分为三大部分：
1. **数据系统基础** - 可靠性、可扩展性、可维护性
2. **分布式数据** - 复制、分区、事务、一致性
3. **衍生数据** - 批处理、流处理、数据系统的未来
