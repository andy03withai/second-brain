# deep-research: 深度调研 v2.1

简化版的深度调研流程。输入主题，输出结构化研究报告。

## 触发方式

```
/r <主题> [--depth standard|deep|comprehensive]
```

**示例**
```
/r AI Agent 在电商领域的应用
/r 具身智能最新进展 --depth deep
```

## 调研流程

### Phase 1: 信息搜索
- 使用 kimi_search 搜索主题相关信息
- 收集 10-20 个高质量来源
- 涵盖：官方文档、技术博客、行业报告、学术论文

### Phase 2: 结构整理
- 按子主题分组信息
- 识别：定义、现状、技术方案、主要玩家、趋势
- 去除重复和低质量内容

### Phase 3: 报告生成
- 按模板生成 Markdown 报告
- 包含：执行摘要、背景、现状、分析、结论
- 保存到 content/deep-research/

### Phase 4: 自动更新
- 更新首页调研报告列表
- 推送到 GitHub
- 返回访问链接

## 深度级别

| 级别 | 搜索量 | 字数 | 用时 |
|------|--------|------|------|
| **standard** | 5-8 来源 | 3-4k | 10-15min |
| **deep** | 10-15 来源 | 5-7k | 20-30min |
| **comprehensive** | 15-20 来源 | 8k+ | 40-60min |
