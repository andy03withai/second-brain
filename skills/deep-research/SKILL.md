# deep-research: 深度调研

针对特定主题进行系统性深度调研，生成长篇分析报告。

## 触发方式

### 命令格式

```
/r <主题> [可选：深度级别/特殊要求]
```

**基础调研**
```
/r AI Agent 在电商领域的应用
```

**指定深度**
```
/r 具身智能最新进展 --depth deep
```

**指定输出要求**
```
/r 大模型推理优化技术 --focus 技术方案对比
```

## 工作流程

### 1. 主题解析
- 提取核心主题词
- 识别调研范围（技术/商业/学术/政策）
- 确定信息源优先级

### 2. 多轮信息收集
| 轮次 | 目标 | 搜索策略 |
|------|------|----------|
| 第1轮 | 基础概念 | 主题定义、核心概念、发展脉络 |
| 第2轮 | 最新进展 | 2025-2026年最新动态、突破 |
| 第3轮 | 深度分析 | 技术细节、竞争格局、关键玩家 |
| 第4轮 | 延伸探索 | 相关领域、未来趋势、潜在影响 |

### 3. 信息整合与分析
- 去重和验证
- 主题分类
- 观点对比（支持 vs 反对）
- 关键数据提取

### 4. 报告生成
生成结构化 Markdown 报告：

```markdown
---
title: "[主题] 深度调研报告"
date: YYYY-MM-DD
research_depth: standard|deep|comprehensive
topics: [相关主题]
sources: [主要信息源]
word_count: ~3000-8000
---

### 3.2 商业模式分析
```

### 5. 保存与交付
- 保存到 `content/deep-research/`
- 提交到 GitHub
- 返回访问链接

## 输出目录

```
second-brain/
├── content/
│   ├── articles/          # 普通文章
│   ├── deep-research/     # 深度调研报告 ⭐
│   │   ├── YYYY-MM-DD-topic-name.md
│   │   └── index.md       # 调研报告索引
│   └── input/             # 每日简报
```

## 深度级别

| 级别 | 搜索轮次 | 字数 | 用时 | 适用场景 |
|------|---------|------|------|----------|
| **standard** | 2轮 | 3000-4000 | 10-15min | 快速了解 |
| **deep** | 3-4轮 | 5000-7000 | 20-30min | 专题研究 |
| **comprehensive** | 5轮+ | 8000+ | 40-60min | 战略决策 |

## 使用示例

### 技术调研
```
/r LLM 推理优化技术 --depth deep
```
重点分析：量化、蒸馏、投机解码、KV Cache 优化等方案对比。

### 商业分析
```
/r AI Coding 工具市场格局 --depth comprehensive
```
涵盖：GitHub Copilot、Cursor、Devin 等竞品分析，市场份额，商业模式。

### 学术综述
```
/r 视觉语言模型 (VLM) 最新进展
```
涵盖：2025-2026 最新论文、SOTA 模型、关键技术突破。

### 政策研究
```
/r 欧盟 AI 法案对中国 AI 企业的影响
```
分析：合规要求、影响范围、应对策略。

## 注意事项

1. **时效性**：报告生成时会标注信息截止日期
2. **信息验证**：关键数据会标注来源，但需用户二次验证
3. **更新机制**：可针对同一主题重新运行 `/research` 获取最新进展
4. **交互优化**：调研过程中可能会询问澄清问题以确保方向正确

## 报告质量指标

- [ ] 信息覆盖全面（技术/商业/学术多维度）
- [ ] 观点平衡（呈现多方观点）
- [ ] 数据准确（关键数据有来源）
- [ ] 结构清晰（易于阅读和检索）
- [ ] 可操作（有明确的结论和建议）
