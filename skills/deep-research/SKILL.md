# deep-research: 深度调研 v2.0

基于 **OpenAI Deep Research** 方法论和 **The Deep Research Machine** 框架的系统性深度调研。

## 核心方法论

### OpenAI Deep Research 四大支柱

| 支柱 | 说明 | 执行方式 |
|------|------|----------|
| **Expansion** | 扩展 | 从核心主题向外延伸，发现相关概念和领域 |
| **Recursive Browsing** | 递归浏览 | 深度钻取关键信息源，层层深入 |
| **Cross-verification** | 交叉验证 | 多源对比，验证信息准确性和一致性 |
| **Synthesis** | 综合 | 整合分散信息，形成统一洞察 |

### The Deep Research Machine 8组件框架

1. **Persona** - 研究者角色定位
2. **Question Framing** - 问题框架
3. **Scope** - 范围界定
4. **Depth** - 深度级别
5. **Citations** - 引用规范
6. **Structure** - 输出结构
7. **Guardrails** - 安全边界
8. **Anti-hallucination** - 防幻觉机制

## 触发方式

```
/r <主题> [--depth standard|deep|comprehensive]
```

**示例**
```
/r AI Agent 在电商领域的应用
/r 具身智能最新进展 --depth deep
/r 大模型推理优化技术 --depth comprehensive
```

## Agentic 工作流程

### Phase 1: 规划 (Planning)
```
输入: 用户主题
↓
1.1 主题解析 → 核心概念、关键词、研究范围
1.2 设定角色 → 领域专家研究员
1.3 制定计划 → 初步研究路径
1.4 确定深度 → standard/deep/comprehensive
↓
输出: 研究计划书
```

### Phase 2: 扩展 (Expansion)
```
目标: 建立主题全貌

2.1 基础概念搜索
   - 主题定义
   - 核心术语
   - 发展历史

2.2 相关领域映射
   - 上游技术
   - 下游应用
   - 平行领域

2.3 关键玩家识别
   - 学术机构
   - 商业公司
   - 开源社区

输出: 主题知识图谱
```

### Phase 3: 递归钻取 (Recursive Browsing)
```
目标: 深度挖掘关键信息

3.1 第一层钻取
   - 高影响力论文/文章
   - 官方文档/博客
   - 行业报告

3.2 第二层钻取 (条件触发)
   - 发现新关键概念 → 钻取概念
   - 发现争议观点 → 钻取多方观点
   - 发现数据矛盾 → 钻取原始来源

3.3 第三层钻取 (deep/comprehensive)
   - 技术细节
   - 实现方法
   - 性能基准

输出: 深度信息池
```

### Phase 4: 交叉验证 (Cross-verification)
```
目标: 确保信息准确可靠

4.1 多源对比
   ┌─────────────────────────────────┐
   │ 来源A ←→ 来源B ←→ 来源C        │
   │   ↓       ↓       ↓            │
   │  一致    矛盾    补充          │
   └─────────────────────────────────┘

4.2 事实核查
   - 关键数据 → 追溯原始出处
   - 引用声明 → 验证原文
   - 时间信息 → 确认时效性

4.3 观点平衡
   - 记录支持方观点
   - 记录反对方观点
   - 标注争议点

输出: 验证后的信息库
```

### Phase 5: 综合分析 (Synthesis)
```
目标: 形成统一洞察

5.1 主题分类
   - 按子主题分组
   - 按时间线排序
   - 按重要性分级

5.2 模式识别
   - 趋势识别
   - 关联发现
   - 缺口识别

5.3 洞察提取
   - 核心发现
   - 关键结论
   - 行动建议

输出: 结构化洞察
```

### Phase 6: 报告生成 (Report Generation)
```
按模板生成 Markdown 报告
↓
保存到 content/deep-research/
↓
提交 GitHub
↓
返回访问链接
```

## 深度级别配置

| 级别 | Expansion | Recursive | Verification | Synthesis | 字数 | 用时 |
|------|-----------|-----------|--------------|-----------|------|------|
| **standard** | 1轮 | 1-2层 | 基础验证 | 基础综合 | 3-4k | 10-15min |
| **deep** | 2轮 | 2-3层 | 严格验证 | 深度综合 | 5-7k | 20-30min |
| **comprehensive** | 3轮 | 3层+ | 多源验证 | 全景综合 | 8k+ | 40-60min |
