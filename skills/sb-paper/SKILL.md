# sb-paper: 论文速读

学术论文分析管道。输入论文，输出结构化理解。

## 检测触发

自动检测以下特征：
- URL 含 `arxiv.org`
- 文件名含 `paper` 标签
- 内容中出现 arxiv ID（格式 `XXXX.XXXXX`）

## 提取字段

| 字段 | 说明 |
|------|------|
| **研究问题** | 论文试图解决什么问题？ |
| **方法** | 使用了什么方法/技术路线？ |
| **核心结论** | 主要发现是什么？ |
| **局限** | 作者承认的局限有哪些？ |
| **可复现性** | 是否有代码/数据公开？ |

## 执行流程

### 1. 识别论文类型

- **理论论文**：提出新理论、框架、模型
- **实证论文**：实验、观测、数据分析
- **方法论文**：新算法、新技术、新工具
- **综述论文**：领域总结、文献回顾

### 2. 提取元数据

- 标题
- 作者
- 发表年份
- 期刊/会议
- arxiv ID

### 3. 结构化摘要

```markdown
## 论文速读

### 基本信息
- **标题**: {标题}
- **作者**: {作者}
- **年份**: {年份}
- **arxiv**: [{ID}](https://arxiv.org/abs/{ID})

### 研究问题
{一句话描述研究问题}

### 方法
{技术路线简述}

### 核心结论
1. {结论1}
2. {结论2}
3. {结论3}

### 局限与未来工作
- {局限1}
- {局限2}

### 可复现性
- [ ] 代码公开
- [ ] 数据公开
- [ ] 实验可复现
```

### 4. 质量评估

- **创新性**：是 incremental 还是 breakthrough？
- **严谨性**：实验设计是否合理？
- **影响力**：引用趋势如何？

## 融入第二大脑

检测到论文链接时：
1. 自动启用 sb-paper 模式
2. 生成论文速读格式
3. 在 footer 显示 arxiv ID

## 示例

输入：https://arxiv.org/abs/2501.12345

输出：
```markdown
## 论文速读

### 基本信息
- **标题**: Attention Is All You Need
- **作者**: Vaswani et al.
- **年份**: 2017
- **arxiv**: [1706.03762](https://arxiv.org/abs/1706.03762)

### 研究问题
如何在没有循环和卷积的情况下，仅靠注意力机制完成序列建模？

### 方法
提出 Transformer 架构，完全基于自注意力机制。

### 核心结论
1. 自注意力在翻译任务上达到 SOTA
2. 训练速度大幅快于 RNN/CNN
3. 可扩展性强，适合并行计算

### 局限与未来工作
- 只验证了机器翻译任务
- 长序列效率待优化

### 可复现性
- [x] 代码公开 (Tensor2Tensor)
- [ ] 数据公开
- [x] 实验可复现
```
