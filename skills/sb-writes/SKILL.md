# sb-writes: 写作消化

通过写作来思考。不是总结原文，而是与原文对话，产出自己的理解。

## 核心概念

写作 = 与文本对话 + 发现断裂 + 填补裂缝

- **对话**：不是复述，是回应
- **断裂**：原文与自己认知的缝隙
- **填补**：用自己的话重建逻辑

## 执行流程

### 1. 准备
获取文章内容 + 用户的批注，作为写作起点。

### 2. 提取核心论点
从原文中提取 3-5 个关键论点，作为写作支架。

### 3. 生成写作提示
针对每个论点，生成一个写作问题：

- "这个观点让你联想到什么？"
- "如果不同意这个观点，从哪里切入？"
- "这个结论的前提是什么？"
- "如果把这个观点推到极致会怎样？"

### 4. 输出写作框架

```markdown
## 通过写作消化

原文核心论点：
1. {论点1}
2. {论点2}
3. {论点3}

写作问题：
- [ ] {问题1}
- [ ] {问题2}
- [ ] {问题3}

你的批注：
{用户原始批注}

建议的写作方向：
- 对比：这个观点与你已知的相关概念有什么异同？
- 应用：这个观点可以在什么场景下使用？
- 质疑：这个结论的边界在哪里？
- 延伸：顺着这个思路还能推出什么？
```

## 质量标准

- [ ] 问题开放：不能是 yes/no 能回答的
- [ ] 连接个人：与个人经验或已知知识建立联系
- [ ] 推动思考：写作后比写作前更清楚
- [ ] 可执行：30 分钟内能写出一段有意义的文字

## 融入第二大脑

在文章收录后，自动在「信息增量」部分添加写作提示，帮助用户通过写作消化知识。
