# 第二大脑 × 李继刚 Skills 整合方案

## 目标
将李继刚的 6 个 skills 融入第二大脑工作流，提升内容处理质量。

## 可复用的 Skills

### 1. ljg-card → 内容可视化
**原功能**：内容转 PNG 视觉图（长图、信息图、海报）

**融入第二大脑**：
- 每篇收录文章自动生成「知识卡片」PNG
- 可用于社交媒体分享
- 放在文章顶部作为视觉摘要

**实现方式**：
```
用户发送 /sb 链接 → 提取内容 → 调用 ljg-card 逻辑 → 生成卡片 → 嵌入文章
```

---

### 2. ljg-writes → 写作消化
**原功能**：通过写作理清思路

**融入第二大脑**：
- 「消化」环节自动触发
- 基于文章内容，生成「如果我来写这个主题」的思考框架
- 帮助用户用自己的话重构知识

**实现方式**：
```
文章收录后 → 分析核心论点 → 生成写作提示 → 辅助用户消化
```

---

### 3. ljg-paper → 深度阅读
**原功能**：学术论文分析管道

**融入第二大脑**：
- 检测技术/学术文章自动启用
- 提取：研究问题、方法、结论、局限
- 生成「论文速读」格式

**实现方式**：
```
检测 arxiv/论文链接 → 启用 ljg-paper 模式 → 结构化输出
```

---

### 4. ljg-plain → 简化输出
**原功能**：简化复杂内容

**融入第二大脑**：
- 每篇文章生成「一句话摘要」和「一段话摘要」
- 降低阅读门槛
- 用于预览和快速浏览

**实现方式**：
```
文章分析完成 → 生成多层级摘要 → 显示在文章头部
```

---

### 5. ljg-word → 词汇学习
**原功能**：英语单词深度解析

**融入第二大脑**：
- 自动识别文章中的专业术语/生僻词
- 生成「词汇卡片」附在文章末尾
- 建立个人术语库

**实现方式**：
```
提取文章关键词 → 深度解析 → 术语库积累
```

---

### 6. ljg-skill-map → 技能地图
**原功能**：查看已安装的所有 skills

**融入第二大脑**：
- 展示当前启用的处理能力
- 用户可查询：「你现在能做什么？」
- 显示处理流程的可视化

**实现方式**：
```
用户查询 /sb-map → 展示第二大脑能力图谱
```

---

## 整合优先级

| 优先级 | Skill | 价值 | 难度 |
|--------|-------|------|------|
| P0 | ljg-plain | 每篇文章都能受益 | 低 |
| P0 | ljg-writes | 提升消化质量 | 中 |
| P1 | ljg-card | 增加分享价值 | 中 |
| P1 | ljg-paper | 学术场景专用 | 中 |
| P2 | ljg-word | 长期积累价值 | 高 |
| P2 | ljg-skill-map | 交互体验 | 低 |
